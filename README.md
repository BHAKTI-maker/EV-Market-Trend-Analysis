# EV-Market-Trend-Analysis
Electric Vehical Market Trend Analysis using Tableau

Project Overview

This project explores electric vehicle (EV) market trends through interactive data visualizations created using Tableau.

Objectives

- Explore patterns and trends in the electric vehicle market.
- Present the available data through clear and interactive visualizations.
- Make market information easier to understand through a dashboard.

Tools Used

- Tableau Public
- Data visualization
- Data analysis
